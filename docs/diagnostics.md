## DNS и proxy

На AmneziaVPN настроены DNS `8.8.8.8`, `1.1.1.1`; на Wi-Fi `1.1.1.1`, `1.0.0.1`. Есть политики NRPT; их полный набор сохранён локально. В пользовательских настройках присутствует адрес proxy, но `ProxyEnable=0`; WinHTTP сообщает DIRECT. Значения proxy и переменных окружения с возможными учётными данными в снимок не включены. В данном снимке имена стандартных proxy-переменных отсутствуют.

Владелец реальных DNS-запросов и поведение при пустом кэше не проверены. DNS-адрес у VPN-интерфейса сам по себе не доказывает, что запросы не выйдут через Wi-Fi.

Секреты и профиль не читались.

Команда `claude` указывает на `C:\Users\cccp1\.local\bin\claude.exe`, версия файла 2.1.284.0. Процесса Claude Code в снимке нет. Запуск платных действий и генерация трафика Claude не выполнялись. Текущий снимок PID и endpoint не доказывает отсутствие краткоживущих дочерних процессов.
